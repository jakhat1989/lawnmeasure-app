# Ohio 88-county imagery register — 19 October 2026

Source of all 88 county names and FIPS codes: [U.S. Census 2026 counties](https://tigerweb.geo.census.gov/tigerwebmain/Files/acs26/tigerweb_acs26_county_oh.html).

**Current status:** The official [Ohio OSIP most-current *cached* aerial imagery](https://maps.ohio.gov/image/rest/services/osip_most_current_cache/MapServer) is configured as the preferred statewide base layer for **all 88 county lookups**. The state notes that the mosaic contains images from **2018–2025** at varying native ground resolutions (metadata updated June 2026). This is not proof each Ohio home is sharp or current. The statewide OSIP 4 collection baseline is **6-inch**, continuing 2025–2028; 3-inch is an optional local enhancement and not statewide. [Ohio OSIP program details](https://das.ohio.gov/technology-and-strategy/ogrip/projects/osip).

**County completion:** 0/88 counties have completed a rigorous three-rooftop visual QA, live source test, actual native-pixel and vintage verification, footprint check, and imagery reuse review. No county is marked complete simply for being served by the Ohio OSIP mosaic.

**County-specific candidates integrated:** Licking County 2025, advertised 3-inch (public [county MapServer](https://apps.lickingcounty.gov/arcgis/rest/services/Basemaps/Imagery2025/MapServer)); Stark County 2025, 6-inch ([county hosted tiles](https://tiles.arcgis.com/tiles/1JiK2PayqrHvvJhM/arcgis/rest/services/Aerial_2025/MapServer)). Actual property views require testing in the app, and requests may fall back to the statewide mosaic.

**Imagery catalog metadata:** [Ohio OSIP 2026 county/vintage index](https://maps.ohio.gov/arcgis/rest/services/Hosted/OSIP_Index_June_2026/FeatureServer/0) publishes footprint, year, and resolution fields; these have not been individually cross-checked for every county. The highest native resolution is not necessarily the latest acquisition. For county-level completion, compare both.

## County verification checklist

- [ ] Verify the source and use/redistribution terms for this county, including attribution and API allowances.
- [ ] Check the newest relevant image acquisition against Ohio's [June 2026 OSIP footprint index](https://maps.ohio.gov/arcgis/rest/services/Hosted/OSIP_Index_June_2026/FeatureServer/0).
- [ ] Record confirmed native image pixel resolution (do not infer it from tile zoom).
- [ ] Test at least three properties in each county (urban/suburban, rural, county edge), inspect rooftops and lot features, confirm image years and alignment.
- [ ] Confirm gaps trigger a government fallback with a clear warning, and the imagery source attribution appears.
- [ ] Mark completed in `ohio_imagery.py` only after all checks pass.
